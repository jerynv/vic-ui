# vic-ui

**Retired, November 2026.**

vic-ui was going to be the one component library behind everything I build. It got as far as buttons, fields, disclosures, sliders, overlays and its own marketing page before I noticed the obvious: there are already enough UI libraries, and nobody asked me for one more.

So it stops here. Projects that use it keep their own copy, and nothing new will ship. The code stays up as a record, not a recommendation.

Read it, fork it, borrow a component. Please don't revive it.
