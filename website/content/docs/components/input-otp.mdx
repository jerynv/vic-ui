The separated cells use vic's original CodeField proportions and active-cell outline. The real input keeps paste, selection, password-manager integration and `autoComplete="one-time-code"`.

Use `surface="flat"` or `surface="bordered"`, or inherit a Surface around the form. Set `aria-invalid` on InputOTP to mark every cell; connect a visible error with `aria-describedby`. The slots also accept `aria-invalid` for individual states.

## Usage

```tsx showLineNumbers
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "vic-ui/ui"
```

```tsx showLineNumbers
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Root CodeField: six fixed digits

```tsx
import { useState } from "react";
import { CodeField } from "vic-ui";

function VerificationCode() {
  const [code, setCode] = useState("");
  return <CodeField label="Verification code" value={code} onChange={setCode} />;
}
```

`CodeField` is the ready-made root API: one native text input, six fixed digit cells, numeric input mode, one-time-code autocomplete and a six-character limit. Formatted clipboard text is normalized before truncation, so `12 34-56` becomes `123456`; selection replacement keeps surrounding digits.

Required props are `label`, controlled `value` and `onChange(value)`. Optional `autoFocus`, `error` and `disabled` support the form state. The host owns verification and submission. CodeField does not expose configurable length, slots, name or ref; use the composable InputOTP API above when those composition needs apply. The two APIs use isolated cell classes and share this documentation family.
