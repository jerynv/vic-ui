## Usage

```tsx showLineNumbers
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "vic-ui/ui"
```

```tsx showLineNumbers
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

## Root Dialog: right-side sheet and nested Escape

```tsx
import { Dialog } from "vic-ui";

<Dialog open={open} onOpenChange={setOpen} title="Report details" side="right">
  {details}
</Dialog>
```

The root Dialog uses a native modal dialog. `side="right"` docks its frame to the right edge; omit it for the existing centered/phone-sheet behavior. `size`, `foot`, `problem`, `onSubmit`, `bare` and `still` remain available.

Native Escape cancellation requests `onOpenChange(false)` and stops propagation, so a nested dialog's cancel event does not also request that its parent close. Each dialog remains controlled by its host. Closing unmounts its presentation; persistent observers belong outside that presentation.
