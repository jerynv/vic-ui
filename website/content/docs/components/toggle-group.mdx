## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "vic-ui/ui"
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

## API reference

See the [full upstream guide](https://base-ui.com/react/components/toggle-group) for additional variants and primitive props. This package uses shadcn's Base UI edition.
