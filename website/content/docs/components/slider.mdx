## Usage

```tsx
import { Slider } from "vic-ui/ui"
```

```tsx
<Slider defaultValue={[33]} max={100} step={1} />
```

## API reference

See the [full upstream guide](https://base-ui.com/react/components/slider) for additional variants and primitive props. This package uses shadcn's Base UI edition.
