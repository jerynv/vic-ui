## Usage

```tsx
import { toast } from "vic-ui/ui"
```

```tsx
toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
})
```

## Setup

Follow [Getting started](/docs) to install the package and its compiled stylesheet. This preview renders the actual `vic-ui/ui` exports.

## API reference

See the [full upstream guide](https://base-ui.com/react/components/toast) for additional variants and primitive props. This package uses shadcn's Base UI edition.
