<ComponentPreview name="avatar" />

Use Avatar for one person's image and fallback, or AvatarGroup for a group. The Ready-made view on this page demonstrates AvatarStack, including overlapping faces and an overflow count.

## Usage

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "vic-ui/ui"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## API reference

See the [full upstream guide](https://base-ui.com/react/components/avatar) for additional variants and primitive props. This package uses shadcn's Base UI edition.
