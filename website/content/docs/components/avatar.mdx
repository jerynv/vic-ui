<ComponentPreview name="avatar" />

Use Avatar for one person's image and fallback. For a ready-made group with overlapping faces and an overflow count, use [Avatar stack](/docs/components/avatar-stack). They serve different layouts and can be used together.

## Usage

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "vic-ui/ui"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Setup

Follow [Getting started](/docs) to install the package and its compiled stylesheet. This preview renders the actual `vic-ui/ui` exports.

## API reference

See the [full upstream guide](https://base-ui.com/react/components/avatar) for additional variants and primitive props. This package uses shadcn's Base UI edition.
