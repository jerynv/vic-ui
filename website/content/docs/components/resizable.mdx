## Usage

```tsx showLineNumbers
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "vic-ui/ui"
```

```tsx showLineNumbers
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>Two</ResizablePanel>
</ResizablePanelGroup>
```

## API reference

See the [full upstream guide](https://github.com/bvaughn/react-resizable-panels) for additional variants and primitive props. This package uses shadcn's Base UI edition.
