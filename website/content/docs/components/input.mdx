TextField from `vic-ui` provides the ready-made input with a label, hint and validation. Its examples are in the Ready-made view on this page.

<ComponentPreview name="input" />

## Usage

```tsx
import { Input } from "vic-ui/ui"
```

```tsx
<Input />
```

## API reference

See the [full upstream guide](https://ui.shadcn.com/docs/components/base/input) for additional variants and primitive props. This package uses shadcn's Base UI edition.
