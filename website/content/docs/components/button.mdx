## Usage

```tsx
import { Button } from "vic-ui/ui"
```

```tsx
<Button variant="outline">Button</Button>
```

## Setup

Follow [Getting started](/docs) to install the package and its compiled stylesheet. This preview renders the actual `vic-ui/ui` exports.

## API reference

See the [full upstream guide](https://ui.shadcn.com/docs/components/base/button) for additional variants and primitive props. This package uses shadcn's Base UI edition.
