## Range selection

Provide a label for each thumb so keyboard and screen reader users can distinguish them.

```tsx
import { Slider } from "vic-ui/ui";

<Slider
  defaultValue={[25, 75]}
  getAriaLabel={(index) => index === 0 ? "Minimum price" : "Maximum price"}
/>
```
