Existing applications can keep importing from `vic-ui`. These components preserve the original prop contracts and styles. New interfaces can use the shadcn Base UI catalogue at `vic-ui/ui`.

```tsx
import "vic-ui/styles.css";
import { Button } from "vic-ui";

<Button look="ink">Save changes</Button>
```
