## Installation

```sh
npm install github:jerynv/vic-ui
```

Import the shared stylesheet once, at your application entry point.

```tsx
import "vic-ui/ui/styles.css";
import { Button } from "vic-ui";

export function SaveButton() {
  return <Button>Save changes</Button>;
}
```

## The component library

Use React 19 and React DOM 19. In frameworks with React Server Components, place interactive examples in a client component. The package includes TypeScript declarations for each component's props.

Import vic's components from `vic-ui`: textured buttons, filled fields, moving tab indicators, disabled explanations, and compositions such as Choice Cards, Typed Confirmation, Flow and Org Mark. Each has a page in the main component catalogue.

For compound controls and additional primitives, `vic-ui/ui` builds on Base UI and shadcn's interaction patterns using the same vic styles. Where both APIs exist, the component page includes a Composable API section. The compiled stylesheet supports both; your application does not need Tailwind.

Try the [Slider](/docs/components/slider) to see a live component and its source, or explore the full catalogue in the sidebar.

Read [Theming](/docs/theming) to customize tokens and connect the icon-based appearance control. Browse the [owned SVG icons](/docs/icons) used throughout the library.
