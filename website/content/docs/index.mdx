## Installation

```sh
npm install github:jerynv/vic-ui
```

Import the shared stylesheet once, at your application entry point.

```tsx
import "vic-ui/ui/styles.css";
import { Button } from "vic-ui/ui";

export function SaveButton() {
  return <Button>Save changes</Button>;
}
```

## The component library

Use React 19 and React DOM 19. In frameworks with React Server Components, place interactive examples in a client component. The package includes TypeScript declarations for each component's props.

The `vic-ui/ui` entry point provides the shadcn Base UI component catalogue with vic/ui's colors, type, spacing, and shape. The CSS is compiled; your application does not need Tailwind.

The existing `vic-ui` entry point and `vic-ui/styles.css` remain available for applications using the original components.

Try the [Slider](/docs/components/slider) to see a live component and its source, or explore the full catalogue in the sidebar.

Read [Theming](/docs/theming) to customize tokens and connect the icon-based appearance control. Existing apps can find their API and examples under [Original components](/docs/compatibility).
