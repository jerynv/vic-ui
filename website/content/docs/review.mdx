---
title: Review components
description: Point at a component, explain the problem, and collect a review across pages.
---

Run `npm run dev:website` and open the local URL printed in your terminal. The feedback toolbar appears at the bottom right on every page, including the icon browser. It only runs locally in development.

1. Click **Start feedback mode**, or press `Cmd+Shift+F` (`Ctrl+Shift+F` on Windows/Linux).
2. Click the element you want changed. Describe the problem, then add the annotation. Drag to select a region when a small or disabled element is difficult to target.
3. Exit feedback mode to use the page and navigate to the next component. Existing notes stay on their own pages.
4. Use the toolbar to edit, delete or copy notes. **Download review** at the bottom left collects your notes from every page into one Markdown file.

The download includes the page, element selector, comment, theme, surface style and viewport size. Keep labels and placeholders visible when reviewing forms; use the Preview surface selector to compare flat and bordered controls.

Feedback stays in this browser. There is no configured server, account, or automatic submission. Copy it into a conversation or attach the downloaded review when you want the changes made. Browser storage is tied to the local host and port, so use the same URL to resume a review.
