## Actual API

- `FocusLayout`: required `children` and `title`; optional `actions`, `back:{to,label,onClick?}`, `org:{name,slug,logo?}`, `steps:readonly {words,at:"done"|"now"|"next"}[]`, `width:"list"`, `tone:"danger"`, `looksOnPhone`, `className`. Host integration uses `brand:ReactNode`, `renderAppearance(placement:"side"|"phone")`, `renderArt({pulse:{n,amount}})` and optional `remember:string`. Source desktop side/form geometry, mobile layout and input/pointer/submit pulse values are retained. No document title mutation, appearance storage, art engine or authentication behavior is supplied.
- `FocusHead`: `title`, optional `back` and `actions`. Uses existing Vic Link, including the consumer's LinkProvider. `FocusMark`: `name`, optional `slug` and `logo`; retains existing logo fallback and source hue geometry.
- `ProviderButtons`: `providers:readonly ProviderKind[]`, `verb:string`, `onChoose(provider)`; optional `disabled` and source-compatible `inline:{size?:"sm"}`. `ProviderKind` is `"google"|"apple"|"microsoft"`. Buttons are native type=button and call the host; there are no POST forms, URLs, callbacks that automatically submit, or provider account operations. Like the source, inline uses compact marks and existing secondary-button sizing; the legacy optional size field does not alter size independently.
- `ProviderChoice`: the same button props plus optional `notice:ReactNode`, controlled `showNotice:boolean`, `noticeLabel:string`, `noticeFocusRef:RefObject<HTMLElement|null>` and `separator:ReactNode` (default `"or"`). A supplied notice remains mounted in the same grid cell to reserve height. Inactive content is hidden and inert. Opening focuses the supplied ref, or the notice container; closing restores the last still-connected, enabled provider trigger. The host owns advice, timers, continue/cancel behavior, navigation and resets. Empty providers render nothing.
- `FormSteps<T extends string>`: `steps:readonly {value:T,label,description?,marker?}[]`, controlled `current:T`, `reached:ReadonlySet<T>`, `onChoose(T)` and optional `disabled`. Unreached/disabled steps remain focusable with descriptions, but cannot invoke onChoose. Current/completed/branch markers and position-only source Motion layout transitions are retained. This component does not validate or advance forms itself.

Public exported types are `FocusStep`, `FocusBack`, `FocusPlace`, `FocusPulse`, `FocusLayoutProps`, `ProviderKind`, `ProviderButtonsProps`, `ProviderChoiceProps`. Six runtime additions: `FocusLayout`, `FocusHead`, `FocusMark`, `ProviderButtons`, `ProviderChoice`, `FormSteps`.

## Adaptation decisions

- Existing Vic Link, ArrowLeftIcon, hueFor and useLogo replace application references. Host slots replace V-Client Wordmark, AppearancePicker/read-save appearance, useTab title ownership and Grain shader. No shader dependency or app appearance/session/URL persistence is bundled. FocusFrame/useFocusFrame are outside this bounded API.
- Grow's source global remember key `"focus"` becomes an optional host-owned remember key, preventing unrelated shell instances sharing height by default. Source dimensions, positioning, pulse behavior and reduced-motion handling remain.
- Provider DB/schema coupling becomes a literal ProviderKind type. Apple invitation advice, five-second countdown, automatic requestSubmit and pageshow reset are host policy and are removed. Exact provider SVG drawings are retained with provenance.
- Inactive provider panels retain visibility/inert semantics and source reserved geometry. Under the composable stylesheet, inherited visibility can settle after the container changes. Focus waits two cancellable animation frames; cleanup cancels either pending frame on controlled change or unmount. Container transitions are explicitly disabled for instant swaps.
- Parent promoted already installed Motion14.9.1 to a runtime dependency. Source used12.43.0. The actual AnimatePresence, motion.li position layout and motion.span transitions are retained and tested against14.9.1; this is not a claim of dependency-version identity.
- Dedicated CSS maps source text/color tokens to Vic semantic equivalents. Parent supplied source-valued progress-complete-fill/text tokens. Source invalid negative steps padding is represented as zero, matching its effective preflight padding. FormSteps' Tailwind block utility becomes a dedicated description class. Application view-transition rules and unused timer styles are excluded. Artwork comments explicitly describe a host slot rather than claiming Grain is bundled.
